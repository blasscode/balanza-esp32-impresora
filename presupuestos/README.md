# Presupuestos

Precios en pesos argentinos relevados en tiendas y en Mercado Libre el 7 y 8 de octubre de 2026, con 15 % de margen para envíos, aumentos e imprevistos. Las planillas calculan solas: se cambian cantidades y margen en las celdas amarillas, y cada precio tiene su link en la hoja *Fuentes*.

| Planilla | Contenido | Total |
| --- | --- | --- |
| `presupuesto_pruebas_balanza.xlsx` | Banco de pruebas (la balanza la aporta el comercio): versión laboratorio y versión lista para instalar | $ 162.507 / $ 200.996 |
| `presupuesto_balanza_con_impresora.xlsx` | Una balanza completa con impresora, incluyendo la balanza base | $ 200.590 |

Cada balanza adicional, sin impresora, lleva un kit de electrónica de unos $ 47.401: ESP32-S3, HX711, fuente, regulador, conectores y un conector USB de panel para enchufar la impresora desde afuera.
